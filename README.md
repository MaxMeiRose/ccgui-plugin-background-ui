# 背景和 UI 优化

从 `ccgui-plugin-model-switcher` 拆出的独立 CC GUI 外观插件。本插件的能力来自 **模型与供应商助手**(Guardian-J/ccgui-plugin-model-switcher)。源码沿用上游 MIT 许可。

## 功能

- 12 套内置主题与自由主题色。
- PNG、JPEG、WebP、GIF 应用背景（单文件不超过 12 MB、解码后不超过 4000 万像素），支持铺满/完整显示和阅读遮罩。
- 在线图库：按分类或关键词从壁纸 API V2.0 获取一批图片，预览后可设为背景或仅保存到历史。
- 壁纸历史管理：本地导入和在线保存共用同一历史，缩略图直接切换、重复图片去重，重启后仍可离线使用。
- 幕布浓度与模糊调节。
- 时间线、会话页签、全局聚焦光晕、细滚动条、代码块和字体优化。
- 配置通过插件独立 KV 保存，不依赖“渠道选择”插件。

## 在线图库

设置页「应用背景 → 壁纸管理」有三个来源：历史记录、在线图库、本地导入。在线图库结果和预览缓存在插件会话中，关闭设置再进入不会重新查询；打开历史不会访问网络。

- 默认来源是 Wallhaven。支持分类、关键词、最低分辨率、排序和真实分页（官方每页 24 张）；随机排序会保留服务端返回的 seed，翻页结果保持同一随机序列。
- UPX8 保留为随机抽样来源；接口 `count` 上限是 10，每批最多 10 张，不支持分页；「再抽一批」会重新抽样，结果可能重复。
- 打开在线图库即自动搜索并下载整批缩略图（并发限流、单张超时 60 秒），加载失败可单独重试，不再需要逐个点「查看」。缩略图实际显示后才记为已看过；开启「隐藏已看过」后，这些记录会跨会话过滤。
- 「设为背景」和「仅保存」下载原图并写入历史。Wallhaven 原图只允许 `w.wallhaven.cc`，缩略图只允许 `th.wallhaven.cc`；UPX8 原图只允许接口文档登记的 CDN 域名。
- 图片通过 `plugin_exec_run` 调用本机 `node` 分片下载（宿主权限 `exec:node`），不新增其他二进制。

Wallhaven 搜索支持标签和多语言，但英文标签通常更准确。UPX8 适合抽样选图，不保证关键词相关性。详见 `docs/public-wallpaper-research.md`。

## 壁纸管理

在“背景和 UI 优化 → 应用背景 → 壁纸管理”中点击缩略图即可切换已导入图片，不需要再次选择文件。原图保存在插件独立存储中，PNG、JPEG、WebP 和 GIF 的原始字节保持不变，包括动画。

- 最多保存 20 张，原图合计不超过 120 MB；满额后会提示先删除记录，不会静默清理旧壁纸。
- 相同图片再次导入会更新名称，不会新增重复记录；同名但内容不同的图片分别保存。
- 上方移除当前背景或切换纯色不会删除历史。历史中的“删除记录”需要确认；删除正在使用的记录会同时停用背景，不影响磁盘原文件。
- 升级时自动把旧版仍保存的当前背景加入历史。旧版已被覆盖、未再保存的更早图片无法恢复，需要重新导入一次。

## 本地构建与安装

Windows PowerShell 中无需 `curl`，直接执行：

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm validate
corepack pnpm build
```

构建后仓库根目录包含：

- `main.js`
- `manifest.json`
- `styles.css`

在 CC GUI 中打开“设置 → 插件 → 从本地目录安装”，选择本仓库根目录。插件启用后，在设置页打开“背景和 UI 优化”。

更新时重新选择同一目录安装；停用或卸载在插件页操作。

## 发布

源码仓库路径预设为 `Mermenglin/ccgui-plugin-background-ui`。创建仓库并推送源码后，打与 manifest 版本完全一致且不带 `v` 的 tag；例如当前版本使用 `0.1.2`。GitHub Actions 会构建并发布三件套与 `checksums.txt`。
